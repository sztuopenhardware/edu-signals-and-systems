# 《信号与系统》交互式 3D 教学仿真实验平台

严格依据 **《信号与系统》课程教学大纲（课程编号：`SG00078`，54 学时 = 36 课堂讲授 + 18 课内实践，教材：奥本海姆《信号与系统》第 2 版）** 研发的全静态、零外部依赖 **交互式三维教学仿真实验平台**。

- **100% 大纲覆盖**：涵盖 **第 1 章 – 第 9 章** 全部课堂讲授知识点，以及教学大纲规定的 **5 项课内必做 MATLAB 仿真实验项目**，共计 **10 大模块、55 个交互式 3D 仿真案例**。
- **按章节下拉菜单快速切换**：顶部导航栏同时提供 **「📑 章节级联下拉选单」** 与 **「章节下拉框 + 本章案例下拉框」** 双模式选择，并支持一键打开全大纲 55 项检索矩阵及 `#case=8.1` 直达锚点分享。
- **三维透视 $\leftrightarrow$ 二维正交无缝变形**：内置高分屏（HiDPI）三维科学计算引擎，支持自由拖拽旋转、平移、缩放、悬停坐标读数、墙面正交阴影投影，以及一键平滑切换 **3D 立体 / 正视 XZ（时域） / 侧视 YZ（频域） / 俯视 XY（复平面零极点与收敛域）**。
- **MATLAB 实时代码联动与随堂自测**：所有 55 个实验均实时同步生成可直接在 MATLAB（R2020a–R2024b+）运行的脚本，并配备随堂自测题与课程思政要点。
- **原生支持 GitHub Pages**：纯静态 HTML/CSS/JS 架构，采用相对路径 `./`，已内置 `.nojekyll` 与 GitHub Actions 自动部署工作流 `.github/workflows/deploy-pages.yml`（同时支持无需服务器直接双击 `index.html` 离线运行）。

## 🚀 本地运行方式

本项目**无需安装 Node.js、Python 或任何第三方依赖包**：

1. **直接打开（最简方式）**：直接在文件资源管理器中双击 [`index.html`](./index.html) 即可在 Chrome / Edge / Firefox / Safari 中完整运行。

## 🌐 发布到 GitHub Pages 指南

> **注意**：上传至公开 GitHub 仓库前，如无需公开学校内部 PDF 原件，可仅上传网页代码文件（`index.html`、`css/`、`js/`、`.nojekyll`、`.github/`、`README.md`）。

### 方式一：网页直接拖拽上传（无需安装 Git 命令行）

1. 登录 GitHub，点击右上角 **New repository** 新建一个公开（Public）仓库（例如命名为 `signals-and-systems-3d`）。
2. 在新建的仓库页面点击 **uploading an existing file**，将本目录下的：
   - `index.html`
   - `.nojekyll`
   - `README.md`
   - `css` 文件夹
   - `js` 文件夹
   - `.github` 文件夹（可选）
   拖入网页上传框，点击 **Commit changes**。
3. 进入仓库顶部菜单 **Settings** $\rightarrow$ 左侧 **Pages**：
   - 若已上传 `.github/workflows/deploy-pages.yml`：在 **Build and deployment $\rightarrow$ Source** 中选择 **GitHub Actions**，工作流将自动完成发布。
   - 或直接在 **Source** 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，点击 **Save**。
4. 等待约 30–60 秒后，刷新 **Settings $\rightarrow$ Pages** 页面，即可获得形如 `https://<你的用户名>.github.io/signals-and-systems-3d/` 的永久在线访问地址！

### 方式二：使用 Git 命令行推送（自动触发 GitHub Actions 部署）

```bash
git init
git add index.html .nojekyll README.md css js .github
git commit -m "feat: publish Signals & Systems 3D interactive simulation platform"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
git push -u origin main
```

推送完成后，前往 GitHub 仓库 **Settings $\rightarrow$ Pages $\rightarrow$ Source** 选择 **GitHub Actions**，即可自动构建并上线。
