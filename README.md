# 《概率论与数理统计》交互式 3D 教学仿真实验平台 (SG02004)

依据**深圳技术大学 · 中德智能制造学院**《概率论与数理统计》（课程编号：`SG02004`，面向电子科学与技术专业，45学时 / 2.5学分）课程教学大纲定制开发的**纯静态 3D WebGL 交互式虚拟仿真实验教学平台**。

---

## 核心特性

1. **教学大纲全覆盖（9 章 29 个独立 3D 交互实验）**
   - 完整覆盖第 0 章绪论及第一章至第八章每一节核心知识点、经典反例（伯恩斯坦正四面体、圆盘均匀分布非独立、$Y=X^2$ 不相关却相依、柯西无期望发散、$U(0,\theta)$ 悬崖似然、样本方差 $n-1$ 无偏修正等）。
2. **双模式章节下拉菜单导航**
   - **顶部章节下拉菜单栏**：按第 0 章 ~ 第八章分组展开悬浮下拉菜单，标注大纲要求等级（`掌握` / `理解` / `了解`）、所属教学周次与电子工程应用标签。
   - **左侧级联下拉选择器**：`章节选择 Dropdown` + `本章实验案例 Dropdown` 双向实时联动，并支持 URL Hash 深链接（如 `#case=3-4`）直接分享指定案例。
3. **电子科学与技术专业深度融合**
   - 融入导体约翰逊-奈奎斯特热噪声、光电探测器光子计数（SPAD散粒噪声）、ADC 量化舍入误差、非线性平方律检波、I/Q 正交调制星座云、无线瑞利衰落包络、串并联冗余可靠度、雷达恒虚警检测（CFAR）及稳压芯片质检等工程实例。
4. **零构建依赖 · 一键部署 GitHub Pages**
   - 纯静态架构（HTML5 + CSS3 + Three.js WebGL + KaTeX），全相对路径引用，内置多 CDN 容灾切换、深色实验模式与**教室投影浅色模式**。

## 本地运行方法

- 直接用现代浏览器（Chrome / Edge / Safari / Firefox）双击打开根目录下的 `index.html` 即可运行。

## 发布到 GitHub Pages 指南

本项目已内置 `.nojekyll` 与 `.github/workflows/deploy.yml`，支持以下任一方式一键上线：

### 方式一：网页端直接上传（最简单，无需命令行）
1. 登录 GitHub，点击右上角 **New repository** 创建一个公开仓库（例如 `prob-stats-3d-lab`）。
2. 点击 **uploading an existing file**，将本文件夹中的 `index.html`、`.nojekyll`、`css/`、`js/`、`.github/` 拖拽上传并点击 **Commit changes**。
3. 进入仓库顶部 **Settings** → 左侧 **Pages**：
   - 在 **Build and deployment** → **Source** 中选择 **Deploy from a branch**，分支选 `main` / `/ (root)` 并保存（或选择 **GitHub Actions** 自动触发内置工作流）。
4. 等待约 30 秒后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线访问！

### 方式二：使用 Git 命令行推送
```bash
git init
git add index.html .nojekyll .gitignore README.md css js .github
git commit -m "feat: 初始化概率论与数理统计 3D 交互式教学仿真平台"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```
推送后在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**（或 `main` 分支根目录）即可自动发布。
